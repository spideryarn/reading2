# Shelf topics eval — the numbers

Generated by `evals/shelf-topics/summarise.ts`. Means over 3 runs per arm. **cov@k**: share of eligible articles in the first k topics. **maxJ / maxO**: the largest Jaccard / overlap coefficient between two of the first 12. **dis / good**: planted distractors / expected-good topics among the first 12 (synthetic cases; a topic counts for an expected-good label when it contains the label's words in order, so *global workspace theory* counts for *global workspace*; distractors match exactly; the figure after the slash is how many of them were candidates at all). **$/call**: OpenRouter's settled cost, or the upstream figure on a BYOK call. **topics**: how many topics the list has (at most 30) — a short row is a real cost. `greg-like` is first: it stands in for Greg's own shelf.

**† jev-floor and jev-floor-0.75 were added after seeing the results; they were not predeclared.** Jev's expected scores never reach 0 (on greg-like, food 0.86, female 0.90), so the greedy still took distractors to fill slots. These arms re-read the saved Jev scores, set any below 1.0 (or 0.75) to 0 — not a topic — and run the same greedy. They make no model call; their cost is jev-score's.
