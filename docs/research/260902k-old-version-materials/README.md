# Materials from the old version, for writing the website

The old Spideryarn repo (`/Users/greg/dev/spideryarn/reading`, 2025) lives only on Greg's Mac.
The remote box cannot reach it, and the
[intent brief](../260902k-spideryarn-reading-intent-brief.md) names its best sources by path alone.
This folder brings the text across so the website work can continue anywhere. Copied 2026-09-03
by two Sonnet agents; the technical side of that repo is covered separately in
[original-version/](../../project/original-version/overview.md).

**Read the header of every file before quoting from it.** Much of the old repo was written by AI
agents, and each file here opens with a best guess at who wrote what, with the evidence. Nothing in
this folder is Greg's word until he has done a second pass and said so; the safe rule is the one in
[positioning.md § Whose words](../../project/positioning.md#whose-words).

## Two things the trawl changed

- **"You're not building an editor, you're building an augmented reader"** is not provably Greg's.
  It sits unattributed inside an AI-written summary of a 2025-06-22 conversation. The brief now
  says so; it is a category to consider, not a quote for the page.
- **The old demo brief leaned on speed** — "reducing the time from paper to understanding by an
  order of magnitude" — which is the framing Greg has since asked us not to emphasise
  ([positioning.md § Depth, and efficiency](../../project/positioning.md#depth-and-efficiency)).
  Kept here as a road not taken.
