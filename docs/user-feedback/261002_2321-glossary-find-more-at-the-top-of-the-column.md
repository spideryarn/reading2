# Glossary: Find more, back, at the top of the column

Greg (admin), 2026-10-02 23:21 UTC, a suggestion, in Glossary mode on
`/read/entropy-26-00481-with-cover-from-taylor-beck-spya-naz564`. Sentry confirmed.

> There used to be a Find More button in Glossary mode. Add it back, at the top of the column

**Ending: Shipped**, on `dev`. Plan
[261003c](../plans/261003c-glossary-find-more-at-the-top-and-metadata-press-closes.md) § 1.

The button was never removed. It was in the band's foot, hidden on a list written by an older
prompt (plan 260929c, because there its run replaces the list rather than adding to it), and
this article's glossary is `glossary/4` against today's `glossary/7`, as are most lists.

It is now the first row of the column, above *Look up a term*, on every owner's list. It reads
**Find more** when a press adds to the list, and **Find terms again** when a press would write a
fresh one: an older prompt, a changed article, or a changed or cleared profile. The server says
which, so the label cannot promise "more" and then replace the list. On Greg's article it will
read *Find terms again* until the list is rewritten once. After that it reads *Find more*.
