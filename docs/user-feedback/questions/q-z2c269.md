Some articles carry their own hover text (an author's `<a title="…">` or `<abbr title="…">`), and it still shows as the browser's grey box in the prose — should we strip it, or turn it into our card?

A. Leave it (recommended for now). It is the author's text, not ours; no code changes. The grey box stays on those links and abbreviations, and on a link it can appear next to our own link card.
B. Strip `title` from articles when they are imported. One line in the sanitiser, which is a security defence, so you decide it. Every author hover is lost, including an abbreviation's expansion, which is real meaning.
C. Keep the words and show them in our card. The words survive and nothing is grey. It costs a small new path: the sanitiser renames `title` to an attribute of ours, and the prose's card reads it. That touches the same defence as B, plus the reading view.

Details

On 2026-10-17 you asked for every regular tooltip to become a rich one, and for a way to keep it that way (spya-q04h98). Every tooltip *our* code draws is now our card, and a test fails on a new native one. What is left is text that arrives inside the article itself: DOMPurify keeps an author's `title` attribute, so a link or an abbreviation that came with one still shows the grey box. That is outside what the test can see, because it is data, not code.

B and C both change `src/sanitize-policy.ts`, which security-map.md lists as a defence, so I have not built either. A would change if you see the grey box often enough to mind; C is the one to pick if an author's hover text is worth keeping.

Acted on 2026-10-18 (queue item qi-ra2qwnfk, plan 261018n). C, kept small. The sanitiser moves an article's own title onto data-author-title, so no grey box is drawn, and the prose card shows the words under "from the article", in the author's typeface with the quote rule down the side. Titles that say nothing new are left out: the link's own words again, the address again (every Wikipedia link), and citation-manager metadata. On the local store that leaves about 25,000 of 170,000, mostly gwern's citations, date and inflation notes, and abbreviation expansions. The glossary does not cover these, so it does not replace them. It applies at import and, because the reading view runs the same policy, to existing articles as they are opened; nothing is re-imported.
