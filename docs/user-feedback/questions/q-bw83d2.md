Background. In your own Feedback list, each report now says one of four things (Open, Needs a decision, Set aside, Shipped), has a number, and may carry a one-line comment an agent wrote about it. Only an admin sees that. Every other reader still sees just Shipped or Not shipped on their own reports.

A. Leave it. Nothing an agent wrote, and nothing about a report being ignored, reaches a stranger.

B. The four statuses and the number for everyone; comments still for admins only. A reader learns their suggestion was set aside rather than wondering. It also tells them when an admin pressed Ignore on their report, which today is invisible to them by design.

C. Comments too. Kinder still. The risk is an agent's sentence that is curt, internal, or says more than it should about a report that tried to misuse the app. It would want a rule that a comment is written for the reader, and the admin feedback page showing every comment so you can read them.

Recommended: A until you have read a few weeks of comments, then B or C.
