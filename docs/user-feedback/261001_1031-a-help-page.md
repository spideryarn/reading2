# A Help page, with contents, search and anchors, kept current on every deploy

Report `spya-p2hamn` (SPIDERYARN-READING2-85), a suggestion, from Greg (admin), 2026-10-01, on
`/read/bf03197835-spya-qfwsw2/metadata`; Overseer queue item `qi-6fkmwvvc`:

> Provide a Help or FAQ page for users that want to understand all of Spideryarn's features. Make
> sure it has a nice table of contents and search bar, and lots of anchor links (so we can link
> directly to places). And include it in footer.
>
> Add a docs/projects/ .md for it, and add a process step when deploying (after Changelog) to make
> sure this Help page has been updated accordingly. And signpost to that doc from new-mode.md ,
> engineering-manager.md , etc.
>
> In the Help page, emphasise the kinds of things that users might not be able to figure out for
> themselves, help them build intuitions, focus on what's valuable, e.g. how should I interpret the
> visuals in the Spine?
>
> While we're at it, perhaps add more (i) icons (with tooltips), and they can link to the relevant
> place in Help.
>
> And anything else you think will help the user, and ensure that we keep this up to date.

**Ending: Shipped**, on `dev`. Plan [261002b](../plans/261002b-help-page.md); the page's doc is
[help-page.md](../project/help-page.md).

What changed: `/help`, signed in and out, linked from the footer, the bottom bar and the command bar.
A grouped contents list, a search box that understands everyday words ("heat" finds the spine), and a
`#` link on every section. About 12,800 words, aimed at what a reader cannot work out alone: the spine
mark by mark, when each mode is worth opening and how to read it, what costs allowance and what does
not, eight questions readers have actually asked. A new mode cannot be added without a Help entry
(the compiler refuses), anchors never break (retired ones redirect), and the Overseer's deploy runbook
gains a step after the release notes: read them, and bring Help up to date.

**Smaller than asked: the (i) icons.** A tooltip card cannot hold a clickable link today
(open-questions.md Q10), and the two obvious places for a new icon have no room — the spine is 12px
wide, and each mode's panel already has its (i) in that corner. So instead of more icons there is one
Help link in the bottom bar that opens at the section for the mode you are in. An (i) whose card links
on into Help waits on Q10.
