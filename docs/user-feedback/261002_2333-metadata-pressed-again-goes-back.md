# Metadata, pressed again, goes back to the article

Greg (admin), 2026-10-02 23:33 UTC, a suggestion, on the Metadata page of
`/read/entropy-26-00481-with-cover-from-taylor-beck-spya-naz564`. Sentry confirmed.

> Tapping on Metadata mode in bottom bar when active should close it

**Ending: Shipped**, on `dev`. Plan
[261003c](../plans/261003c-glossary-find-more-at-the-top-and-metadata-press-closes.md) § 2.

Since 261002g a second press on the mode you are in closes it, but Metadata is a page rather
than a mode, so it was left out. On the Metadata page its button pointed at itself. It now
points back at the article with the same query string, so you land in the paragraph and the mode
you came from (`?at=`, `?mode=`, `?margin=`). ⌘-Enter / Ctrl-Enter does the same there.
