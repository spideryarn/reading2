**Ending: Shipped**, on `dev`. Plan
[261004f](../plans/261004f-glossary-find-more-always-adds-across-prompt-versions.md). It follows
[the note for spya-s660yh](261002_2321-glossary-find-more-at-the-top-of-the-column.md), which put
the button at the top and gave it the label he could not read.

The button said *Find terms again* because its run replaced the list whenever the list had been
written by an older version of the glossary prompt, and the prompt had changed five times in eight
days. Now such a list is **added to**: the button says **Find more** and a press asks for up to 20
more terms, keeping every term already there. If a press finds nothing, the row says so.

A press still replaces the list when the article or the reader's profile has changed since the
list was written. There the button says **Write a new list**, with one sentence under it saying
why and that added terms are kept.

Given up, and in the plan: older entries are no longer rewritten in the newer, plainer style by
this button, and a cited paper already on a list stays until it is hidden.
