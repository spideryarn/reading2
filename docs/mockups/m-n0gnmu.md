An example, so this page is not empty. A mockup is a file in docs/mockups/ (the format is in docs/project/admin.md § /admin/mockups). Text like this is plain. A block between two lines of three backticks is monospaced, so ASCII lines up:

```
+--------------------------------------------+
| Admin › Mockups                            |
+-----------+--------------------+-----------+
| id        | title              | made      |
+-----------+--------------------+-----------+
| m-n0gnmu  | Example: what a …  | 2026-10-28|
+-----------+--------------------+-----------+
```

A line "image: m-n0gnmu-<name>.png" would show a picture saved beside the file. This one has none. A mockup is on this page after the next deploy, not at once.
