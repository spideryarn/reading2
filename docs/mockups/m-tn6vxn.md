One way an agent can show you a shape: drawn in text, in a monospaced block. This one is option 1B of the question about what the Overseer says only in the terminal (q-cgpett): a notice, which needs no answer, shown above the questions in Needs a decision.

It costs nothing to make and can go straight into a question, so you can see it on your phone without opening anything. What it cannot show is colour, type or spacing, so it is good for layout and order, and poor for how something will feel.

```
+------------------------------------------------+
| Write   Earlier   Needs a decision (3)         |
+------------------------------------------------+
| NOTICES - nothing to answer                    |
|                                                |
|  ! The deploy is held: dev's tests are red     |
|    since 14:02. A fix is on its way.           |
```
