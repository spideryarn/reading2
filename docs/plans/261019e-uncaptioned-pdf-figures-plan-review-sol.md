4. **blocker — Empty-caption refs can silently move an existing block id onto a different figure.**  
   Evidence: the ref hashes PDF, page, per-page ordinal and caption ([src/pdf-figures.ts:888](/var/tmp/spideryarn-worktrees/fbx9gn3d-rovelli-lost-diagram/src/pdf-figures.ts:888)). With an empty caption, ordinal is the only within-page identity. If a later transcription inserts a previously missed uncaptioned figure first, that new figure receives the old ordinal-1 ref; the old first figure receives the old ordinal-2 ref. `emptyKey` includes the marker attribute ([src/blocks.ts:829](/var/tmp/spideryarn-worktrees/fbx9gn3d-rovelli-lost-diagram/src/blocks.ts:829)), so it confidently transfers the old ids to the wrong figures. Its identical-empty-block count guard cannot help because every marker key is individually unique. This is semantic ordinal reuse, not a cryptographic collision; the 128-bit digest collision risk itself is negligible.  
   Fix: give uncaptioned figures an identity based on their stable raw-record anchors, with an occurrence only among identical anchor signatures. Bump the ref version as required by its contract ([src/pdf-figures.ts:845](/var/tmp/spideryarn-worktrees/fbx9gn3d-rovelli-lost-diagram/src/pdf-figures.ts:845)). If no defensible identity is available, explicitly remint these empty blocks; losing an anchor is safer than moving it.
