# GPT Sol — first plan review of 261101d (2026-11-01)

Read-only review of the first draft of [261101d](261101d-structure-fourth-level-staged-second-call.md), which proposed switching on the September deepening wave. Verbatim.

1. **P1 — The existing wave is not limited to depth-2 sections, so it does not guarantee the tree shape the reading view expects.** `deepenTree` recursively selects every childless internal node, irrespective of depth ([structure-deepen.ts:2526](src/structure-deepen.ts:2526)); tests explicitly expand root and depth-1 targets ([structure-step-deepen-wave.test.ts:1933](tests/structure-step-deepen-wave.test.ts:1933), [structure-step-deepen-wave.test.ts:2011](tests/structure-step-deepen-wave.test.ts:2011)). A ragged depth-1 part can therefore gain depth-2 sections instead of a depth-2 section gaining depth-3 sub-sections. This will not break tree invariants: Structure and Outline recurse safely, and `sectionDepth` caps `?at=`, Quiz and return positioning at depth 2 ([position.ts:72](src/web/position.ts:72)). Arc and existing questions also remain attached to their old ancestors. But the rollout can pass without delivering the claimed feature. **Change:** constrain this rollout’s frontier to `depth === 2`; gate that every new internal node is depth 3 beneath a depth-2 parent and has only leaf children.

2. **P1 — The heading rule can publish a false hierarchy, and the paper gate currently permits it.** The scoped prompt says every authored heading begins a child, without distinguishing immediate subheadings, deeper headings or a swallowed sibling ([structure-expand.ts:267](src/structure-expand.ts:267), [structure-expand.ts:290](src/structure-expand.ts:290)). Thus “2.5” swallowed by 2.4 becomes an explicit child of 2.4; likewise 2.4.5(a–c) can be flattened into siblings of 2.4.5. That is worse than today because Structure now asserts the wrong relationship, while `?at=` and Quiz still attribute those passages to depth-2 section 2.4. The proposed gate only forbids the mis-tagged headings at depths 1–2, so it would pass this error ([plan:99](docs/plans/261101d-structure-fourth-level-staged-second-call.md:99)). **Change:** annotate the paper’s exact permitted depth-3 starts—2.4.1 through 2.4.6—and forbid 2.5 and 2.4.5(a–c) there. Generalise that gate using heading numbering, neighbours and tags. Because this call cannot promote 2.5 to a sibling, skip such a target or repair wave 1 separately; do not demote it.

3. **P1 — Gates 2–4 are too weak and partly mismatched to production.** Gate 2 says “structural blocks”, but the reused scorer measures raw span length ([score.ts:104](evals/structure-fourth-level/score.ts:104), [score.ts:124](evals/structure-fourth-level/score.ts:124)); production uses `structuralBlocksIn` ([structure-cascade.ts:479](src/structure-cascade.ts:479)). Gate 3’s counts and leaf equality can miss changed titles, gists, questions, source headings or parentage, all reader-visible fields that reconstruction is supposed to preserve ([structure-cascade.ts:1577](src/structure-cascade.ts:1577)). Gate 4 merely reports refused and oversized targets, although repeated refusal silently preserves wave 1 and continues ([structure-deepen.ts:1513](src/structure-deepen.ts:1513)). **Change:** use the production structural-block predicate; compare every pre-existing node’s path, range, title, gist, question and source heading plus exact leaf coverage; require zero refusal/oversize/out-of-time for heading-selected targets; and make immediate-author-subheading recall a gate rather than a reported statistic.

4. **P1 — Deadline exhaustion can silently publish the undeepened tree, and none of the gates exercise it.** Admission reserves 60 seconds ([structure-deepen.ts:1048](src/structure-deepen.ts:1048)), but an exhausted wave returns the original tree with `outOfTime` rather than failing ([structure-deepen.ts:2738](src/structure-deepen.ts:2738)). `generateStructure` then writes labels and completes normally because only thrown errors set `deepenFailed` ([structure.ts:3214](src/structure.ts:3214)). **Change:** when `outOfTime > 0`, request another lease window using the existing `NeedsAnotherWindow` mechanism; only make an explicit final-window fallback. Add a deadline-injected test and gate `outOfTime === 0` and `withheld === 0`.

5. **P1 — The cost/time gate omits two likely production multipliers: labels and concurrent load.** Deepening changes the lowest-level sibling sets that the later labels step sends to the model ([labels.ts:796](src/labels.ts:796)); merely reporting planned batch count does not measure that step’s real time or cost. Also, eight expansion calls per job across six jobs permits 48 simultaneous calls, a value the code itself says was chosen rather than demonstrated ([structure-deepen.ts:530](src/structure-deepen.ts:530), [structure-deepen.ts:549](src/structure-deepen.ts:549)). Medians can also be diluted by articles with no eligible targets. **Change:** gate total Structure-plus-labels cost and wall time on the eligible subset; add a six-job concurrent run requiring no 429/failure/deadline fallback; report the affected-set tail, not just medians. Include one high-powered article or apply its documented Opus cost multiplier. The plumbing itself is sound: live calls use the AI gateway, and `power` participates in the checkpoint key ([structure-deepen.ts:342](src/structure-deepen.ts:342), [structure-deepen.ts:848](src/structure-deepen.ts:848)).

6. **P2 — The gates do not catch plausible but poor new boundaries, titles or gists.** September’s repeated run changed fan-out for 15 of 22 parents, visibly moving the tree despite similar aggregate scores ([260904d plan:1881](docs/plans/260904d-deepen-fat-sections.md:1881)). Counts, leaf preservation and two successful runs do not establish reader-visible quality or stability. **Change:** compare the two runs per parent for boundary/fan-out stability, and manually review every invented split on the fresh corpus for boundary fit, fragmentation, title and gist fidelity before enabling the default.

7. **P2 — A narrower first rollout is simpler and better aligned with the request.** The broad recipe also opens headingless sections over 2,000 words and asks the model to invent boundaries ([structure-cascade.ts:156](src/structure-cascade.ts:156)). That introduces most of the subjective quality, stability and cost risk without being needed to expose authored fourth-level structure. **Change:** first enable only depth-2 targets containing unresolved immediate author subheadings, with invention limited to the necessary opening prose child; measure the 2,000-word/topic-shift heuristic as a later rollout. Also qualify “new articles get the level”: sliced articles bypass deepening entirely ([structure.ts:2690](src/structure.ts:2690)). No September-checkpoint purge is needed because the key includes prompt, body, seed, recipe and power.

**Verdict:** P1 changes are required before building—the current plan can ship the wrong depth, explicit heading demotions and silent deadline fallbacks while all stated gates pass.
