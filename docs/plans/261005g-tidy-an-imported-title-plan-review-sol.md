2. **P2 — The acronym count needs cleaner evidence.** The body **is available**: HTML has Readability’s `article.textContent` and HTML `article.content` ([extract.ts:483](/home/greg/code/spideryarn2/.claude/worktrees/fbfyj3m4-import-title-tidying/src/extract.ts:483)); PDF has the `mended` typed transcription records before title creation ([pdf-read.ts:3643](/home/greg/code/spideryarn2/.claude/worktrees/fbfyj3m4-import-title-tidying/src/pdf-read.ts:3643)). Neither is necessarily paragraph-only prose. PDF transcription is instructed to omit running heads ([pdf-read.ts:460](/home/greg/code/spideryarn2/.claude/worktrees/fbfyj3m4-import-title-tidying/src/pdf-read.ts:460)), but that is not a guarantee.

   Two capitalised repetitions of a title or shortened running head can preserve ordinary words as supposed acronyms. The per-word condition also accepts an entirely uppercase body unless there is a separate guard. Specify paragraph evidence, excluding headings, title repetitions, publisher furniture, code and references; use PDF record text rather than raw pass-0 text. Add adversarial tests for shortened running heads and an uppercase body. Even then, NASA appearing once—or never—in the body remains a known limitation, so “mostly covers” needs evidence.

3. **P2 — Narrow recasing when the language is unknown.** Treating every PDF as English is explicitly proposed at [plan:44](/home/greg/code/spideryarn2/.claude/worktrees/fbfyj3m4-import-title-tidying/docs/plans/261005g-tidy-an-imported-title-and-keep-the-original.md:44). `EL ORDEN DEL TIEMPO` becomes English-style `El Orden Del Tiempo`; Turkish `I`/`İ` can acquire the wrong lowercase characters. For a simple v1, at least leave non-ASCII cased titles unchanged when the language is unknown. Document unknown-language Latin titles as a remaining limitation; do not add a language detector just for this feature.

4. **P2 — Specify punctuation and name handling before calling the rule complete.** “Each word becomes a capital and lower-case letters” leaves important cases undefined ([plan:32](/home/greg/code/spideryarn2/.claude/worktrees/fbfyj3m4-import-title-tidying/docs/plans/261005g-tidy-an-imported-title-and-keep-the-original.md:32)). Require `ROVELLI'S → Rovelli's`, `DON'T → Don't`, and `O'BRIEN → O'Brien`, including curly apostrophes. A punctuation-splitting implementation produces `Rovelli'S` or `Don'T`; a whitespace-only implementation produces `O'brien`. `McDONALD` correctly makes the whole title mixed-case and therefore untouched; `MCDONALD → Mcdonald` remains an unavoidable name error unless the body supplies its spelling. Explicitly test that limitation.

   The basic convention is otherwise fine: `The Order of Time`, colon subtitles, `World War II`, `Henry VIII`, `CO2`, and initials are reasonable results. Preserve spaced initials such as `J. A. SMITH`, including the `A.`. Validate Roman numerals rather than accepting every run of Roman-numeral letters: `CIVIL` is a word, and `MIX` is ambiguous. Title case for news headlines is a destination style choice, not inherently a defect.

6. **P2 — The `plainTitle` backstop can make the stored pair disagree.** `plainTitle` expressly is not idempotent for double-encoded entities ([html.ts:166](/home/greg/code/spideryarn2/.claude/worktrees/fbfyj3m4-import-title-tidying/src/html.ts:166)), and `metaColumns` runs it again ([artifacts-pg.ts:842](/home/greg/code/spideryarn2/.claude/worktrees/fbfyj3m4-import-title-tidying/src/store/artifacts-pg.ts:842)). I verified that `THE &amp;lt;i&amp;gt;ORDER&amp;lt;/i&amp;gt; OF TIME*` becomes encoded markup after one pass and plain words after two. If only `title` receives that second pass, `titleOriginal` retains a different representation; restoring it through rename will not undergo the same cleanup. Define the original as the pre-tidying **plain display title**, apply consistent normalisation to both stored fields, and pin this example in a round-trip test. Do not introduce recasing into the storage backstop.

10. **P3 — Existing rows and fingerprints: fine.** The fingerprint hashes the extracted title verbatim ([source-hash.ts:359](/home/greg/code/spideryarn2/.claude/worktrees/fbfyj3m4-import-title-tidying/src/source-hash.ts:359)); changing its case therefore changes freshness across the listed modes.
