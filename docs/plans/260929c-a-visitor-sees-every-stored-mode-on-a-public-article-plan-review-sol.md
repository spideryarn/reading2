Add exact-key mutation tests for both nested locations.

3. **P1 — Diagram’s stored Illustrated output is missing from the audit.** The plan says Diagram is complete because visitors receive Sketch (`…visitor-sees-every-stored-mode…md:70`), but `illustrated` is a separate stored artefact (`src/illustrated-plate.ts:396`, `src/store/export.ts:449`). 4. **P1 — The per-stage silent-failure checklist is incomplete.** The governing recipe requires `public-imports`, `public-reads`, `public-visibility-pg`, nested DTO, network/deep-link, shared-inventory, privacy-page and access-sharing coverage (`docs/plans/260904c-more-modes-on-a-shared-link.md:166`). Export is already covered for Trajectory/FAQ/Citations, and Debate’s referenced Stage 4 names its export work.
