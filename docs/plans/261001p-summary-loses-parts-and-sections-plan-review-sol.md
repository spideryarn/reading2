Move `deep` from `REMEMBERED` to `NEVER_REMEMBERED` instead: stored copies are filtered out, while incoming legacy links still suppress restoration.

- Since `simple` becomes the default, `subModeParams()` should clear it rather than writing redundant `?summary=simple`, matching the other default sub-modes ([sub-modes.ts](/home/greg/code/spideryarn2/.claude/worktrees/fb7q-7r-summary-remove-parts/src/web/sub-modes.ts:201), [sub-modes.ts](/home/greg/code/spideryarn2/.claude/worktrees/fb7q-7r-summary-remove-parts/src/web/sub-modes.ts:226)). Keeping `MODE_TARGET.summary` non-arming is otherwise consistent with `ModeBoundary`: make `bandTarget(summary, …)` return `simple` unconditionally. A top-level Summary press creates no token, so the boundary sees nothing; slider and command-bar sub-mode presses do create `simple`, which the mounted owner band can claim or the boundary can retire. No orphaned token is introduced.

The deletion of `SummaryPanel` is reasonable; I do not see a materially simpler component structure. The useful simplifications are retaining `deep` as a retired last-view key and computing one shared `bandShape` value in `Reader` (whether through the proposed helper or a local constant).
