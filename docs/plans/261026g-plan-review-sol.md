1. **P1 — Stage 4 / activation shape:** [plan § Stage 4](/var/tmp/spideryarn-worktrees/fbc5gvp0-where-it-sits-layout/docs/plans/261026g-where-it-sits-made-clear-runs-itself-and-reaches-the-margin.md:138), [activation.ts § delegated targets](/var/tmp/spideryarn-worktrees/fbc5gvp0-where-it-sits-layout/src/web/activation.ts:184), [activationForSources](/var/tmp/spideryarn-worktrees/fbc5gvp0-where-it-sits-layout/src/web/activation.ts:620). The plan promises two arms, but activation deliberately guarantees one token per press. Do not change its return type to an array or add a second ad-hoc arm; that reopens orphan-token and Back/Forward spending bugs. Add one composite `sources-where` target, owned only by `WhereBand`. Its coordinator should wait for both reads, then:

   - if both are missing, enqueue one unforced job with `situate` preceded by `bibliography`;
   - if only Bibliography is missing, call only `bibliography.ensure()`;
   - if only Situate is missing, call only `situate.ensure()`;
   - treat any stored Situate dossier, including stale/outdated, as present.

   This preserves one token, one owner, one session attempt, and avoids accidentally rerunning a stored dossier. Do not put `useAutoRun` unconditionally inside `useSituate`: Investigate also mounts that hook.

The genuinely simpler alternative is an originless one-shot Ask button, like Summary’s paragraph question, but that intentionally gives up the mark and way back.

5. **P2 — Stage 2 / folded focus and scrolling:** [plan § folded groups](/var/tmp/spideryarn-worktrees/fbc5gvp0-where-it-sits-layout/docs/plans/261026g-where-it-sits-made-clear-runs-itself-and-reaches-the-margin.md:114), [item-focus.ts § useLandOnItem](/var/tmp/spideryarn-worktrees/fbc5gvp0-where-it-sits-layout/src/web/item-focus.ts:71). `onLand` cannot open a folded group: the hook returns while `drawn` is false and calls `onLand` only afterwards.    - test a focus into a non-default folded group, an unknown old finding, retry after a failed GET, and a rerun whose first group changes.
