1. **P1 — [plan:49](/home/greg/code/spideryarn2/.claude/worktrees/fb93-long-pdf-hierarchy-fails/docs/plans/261001s-fb93-long-pdf-hierarchy-asks-again.md:49), [hierarchy.ts:1344](/home/greg/code/spideryarn2/.claude/worktrees/fb93-long-pdf-hierarchy-fails/src/hierarchy.ts:1344): “missing” is defined too broadly.**  
   If `[validStart, 3]`, `[validStart]`, or another malformed value is treated as “no claim,” a real start claim is discarded. The child can then begin at the previous child’s end instead of `validStart`, attaching its title and gist to the wrong prose without a boundary-repair measurement. Count only an absent property or `null` as missing. A non-array, wrong-length array, or non-string member should remain malformed and fail. An empty string is a string that resolves to no block, so it should remain an invented/unresolvable-id failure. If partial ranges are ever to be recovered, that needs an endpoint-by-endpoint design, not the proposed all-or-nothing “rangeless” category.

3. **P2 — [plan:125](/home/greg/code/spideryarn2/.claude/worktrees/fb93-long-pdf-hierarchy-fails/docs/plans/261001s-fb93-long-pdf-hierarchy-asks-again.md:125), [hierarchy.ts:1501](/home/greg/code/spideryarn2/.claude/worktrees/fb93-long-pdf-hierarchy-fails/src/hierarchy.ts:1501), [heading-snap.ts:118](/home/greg/code/spideryarn2/.claude/worktrees/fb93-long-pdf-hierarchy-fails/src/heading-snap.ts:118): the Part 1 test matrix omits the riskiest edge.**  
   The correct walk is:

   - First rangeless child: pin to the parent start; skip its head claim; `snapStartsToHeadings` intentionally skips the first kept child.
   - Middle rangeless child: use the preceding resolved end; measure only that preceding-end claim. At the following boundary, measure only the next child’s start.
   - Last rangeless child: use the preceding resolved end and skip the closing-end claim.

   `snapStartsToHeadings` is safe because it reads `kept.start` and `sourceHeading`, never `range`. The dangerous old assertions are the span reads in `backwards`, `claimed`, fallback, head, both interior claims, and especially the tail. Add a rangeless-last test, one-sided-boundary tests, and a rangeless child with a heading snap. Also decide explicitly whether a sole rangeless child later removed as a redundant rung still counts; because the metric is meant to detect prompt drift, I recommend counting it even though the node is collapsed.

4. **P2 — [plan:84](/home/greg/code/spideryarn2/.claude/worktrees/fb93-long-pdf-hierarchy-fails/docs/plans/261001s-fb93-long-pdf-hierarchy-asks-again.md:84), [jobs.ts:2463](/home/greg/code/spideryarn2/.claude/worktrees/fb93-long-pdf-hierarchy-fails/src/jobs.ts:2463): “first duration plus a margin” needs a conservative formula.**

Test this with controlled unequal call durations, not only “one second left” versus “ten minutes left.”
