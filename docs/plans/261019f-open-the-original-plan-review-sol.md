F1 — High: `original` already aliases Plain mode. The plan’s claim that it matches nothing is false. With the proposed row, both Plain and the action get an alias-prefix match from `original`; modes precede actions, so Plain remains first. Either remove `original` from Plain’s aliases or give the new row a label beginning with “Original”. F2 — High: `opensOnly: false` protects the model-pick/RUN_AT_ONCE path, but not dictation. A double press on Stop invokes `onDone` from an effect after transcription has arrived, which then calls Enter → `activate` → `command.run()`. That is outside the original user-activation task. The web popup can therefore be silently blocked; the PDF path falls back to replacing the current tab. The row needs an explicit “requires transient user activation” guard so dictation leaves it selected for a fresh Enter/click. F3 — High: the two dynamic descriptions cannot share one catalogue key safely. The catalogue requires every `(id, label)` pair to have identical descriptions and aliases across contexts, while the plan gives `action:original` / “Open the original” a PDF description or an article-specific host description. Representing both contexts will fail the collision check; representing only one freezes misleading words into the server catalogue. Use one stable generic description, such as “The web page or uploaded PDF this article was made from, in a new tab.” [command-pick-catalogue.test.ts](/var/tmp/spideryarn-worktrees/fb-r6a5s5-open-original/tests/command-pick-catalogue.test.ts:216)

F4 — Medium: the alias set is broader than necessary and sometimes false for the current arm. `publisher` on an uploaded PDF opens the upload; `original pdf/file` on a web article opens a page; and `where it came from` appropriates Metadata’s advertised purpose. Conversely, natural phrases `open original` and `view original` do not directly match because matching is contiguous. Bare `source` is correctly excluded; `source page`/`source url` do not collide with Sources or Metadata for those full queries, and the Share rows do not collide. A smaller, literal set would be safer.

F5 — Medium: tests should cover the PDF command path and the dictation path, not only web `window.open`. Specifically: blank tab opens before the first await; success navigates it; failure closes it and keeps the bar open; dictation does not attempt a popup; and both web/PDF catalogue contexts produce one stable option.

F6 — Low: the Metadata bug is real, and `meta.source === "pdf"` is the correct fix. `.html` and `.htm` both return `null` from `convertedFormatFromName`, while `sendSource` serves only `readPdf`; the defect also covers other filename/content mismatches whose stored source kind is HTML.
