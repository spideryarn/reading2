1. **P1 — The root `ResizeObserver` can oscillate; the plan’s “narrowing only makes the page taller” argument is false.** Structure has a discontinuous layout threshold in [src/web/layout.ts:838](/home/greg/code/spideryarn2/.claude/worktrees/fb-y3747g-hscroll-colwidth-archive/src/web/layout.ts:838). The observer currently updates state directly at [src/web/reader/measure.ts:35](/home/greg/code/spideryarn2/.claude/worktrees/fb-y3747g-hscroll-colwidth-archive/src/web/reader/measure.ts:35), unlike the rAF-coalesced observer in [src/web/dock-fit.ts:257](/home/greg/code/spideryarn2/.claude/worktrees/fb-y3747g-hscroll-colwidth-archive/src/web/dock-fit.ts:257). **Fix:** reserve scrollbar space with `scrollbar-gutter: stable` on the root, and coalesce the observer through `requestAnimationFrame`. Test archive → unmount → failed network request → cached reopen.

4. **P2 — Two reading-view fullscreen dialogs retain the same classic-scrollbar `100vw` defect.** `.sk-full` at [src/web/styles/diagram-sketch.css:192](/home/greg/code/spideryarn2/.claude/worktrees/fb-y3747g-hscroll-colwidth-archive/src/web/styles/diagram-sketch.css:192) and `.ill-full` at [src/web/styles/diagram-illustrated.css:225](/home/greg/code/spideryarn2/.claude/worktrees/fb-y3747g-hscroll-colwidth-archive/src/web/styles/diagram-illustrated.css:225) both use `width/max-width: 100vw`, so their right edge can sit beneath a classic scrollbar. 5. **P2 — The 15px disagreement between JS and the 731px CSS breakpoint is functional, not merely cosmetic.** In the 732–746px `innerWidth` interval with a 15px scrollbar, JS sees a narrow layout while `@media (max-width: 731px)` does not apply. That media query supplies horizontal overflow and non-shrinking behavior for `.controls` at [src/web/styles/narrow-window.css:135](/home/greg/code/spideryarn2/.claude/worktrees/fb-y3747g-hscroll-colwidth-archive/src/web/styles/narrow-window.css:135), as well as prose, masthead and dock geometry—not just shorter labels. **Fix:** drive reading-view narrow rules from the same scrollbar-excluded measurement, preferably via a root class/data attribute or container query. Do not simply raise the breakpoint to 746px because scrollbar widths and overlay behavior vary.

The band formula itself is sound: standard mode starts growing after 1220px, reaches 460px at 1280px and caps at 544px from 1364px; roomy mode’s crossover is 1268px. Structure retains its separate 609–705px ladder, and I found no 544px-band incompatibility in marginalia, dock fitting, chat, tooltips or headers.
