2. **P2 — The module-level `PrivateCopy` one-shot is not a sound navigation intent.**  
   Evidence: the proposed mark is set before navigation and deliberately disappears in a new tab ([plan](/var/tmp/spideryarn-worktrees/fbahvk74-import-public-offer/docs/plans/261009j-a-public-copy-offered-at-import.md:101)). `Link` invokes its supplied `onClick` before deciding whether the click is a Command/Ctrl/Shift click or targets another tab ([Link.tsx](/var/tmp/spideryarn-worktrees/fbahvk74-import-public-offer/src/web/Link.tsx:37)).    **Fix:** encode the intent in a durable distinct route, such as `/add-own/<encoded-address>`, parsed into `{ kind: "add", url, ownCopy: true }`. Include the intent in `addAddress` so account-change and visit guards distinguish it. This works for plain clicks, new tabs, reloads, and copied links without mutable global state. Test modified clicks, cold loads, StrictMode, and reader changes.
