The quote percentage does not model the UI’s actual default, although the discrepancy only makes it more permissive. `markedQuotes` snaps `0.65` to the nearest score present in each article before filtering ([QuotesPanel.tsx:507](</home/greg/code/spideryarn2/.claude/worktrees/fb-prioritised-defaults/src/web/QuotesPanel.tsx:507>)); the SQL measures a literal `score >= 0.65`. Snapping upward cannot hide an additional quote, because the chosen stop is itself the first score above the boundary; snapping downward can reveal the group immediately below it. Therefore 88% is a lower bound, not necessarily the actual mean, and some lists may show 100%. Lowering from 0.80 to 0.65 also cannot produce a higher effective stop than before, so the feared “snap up and hide more than today” regression does not occur.
