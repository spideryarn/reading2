Suggested fix: specify `owner !== null && owner !== DEFAULT_ENGINE`, index by that narrowed owner, and test that mounting with Experimental off and no active call invokes neither engine’s `stop()`. The in-progress code currently contains this guard ([useLive.ts:119](/var/tmp/spideryarn-worktrees/fbt858ug-live-default-engine/src/web/live/useLive.ts:119)); the plan should require it rather than describe the unsafe predicate.
