- **F1 — P1, established: the source checks do not establish whose influence is being scored.**  
  `pageNamesTitle` accepts the work’s title anywhere in an extract; quote matching independently accepts words elsewhere in it. An extract saying “Target Work … Other Work has 8,000 citations” passes both checks. That contradicts the plan’s explicit guarantee that another paper’s count cannot be taken. See [citations.ts:988](/home/greg/code/spideryarn2/.claude/worktrees/citations-influence-unknown/src/bibliography.ts:988). The existing [resultIsTheWork check](/home/greg/code/spideryarn2/.claude/worktrees/citations-influence-unknown/src/citation-lookup.ts:310) strengthens page identity but still cannot identify the subject of an arbitrary quotation.  
  **Fix:** require evidence that connects the standing claim to the cited work—for a conservative v1, a quotation that identifies the work itself, or a verified page dedicated to that work. Reject ambiguous multi-work extracts. Include the counterexample above as a negative test.

- **F2 — P2, established: naming `findQuote` leaves the verification contract incomplete.**  
  Its default is `"forgiving"`, which deletes whitespace and can accept different words. The source explicitly says to use `"spaced"` for quotations. See [quote-match.ts:229](/home/greg/code/spideryarn2/.claude/worktrees/citations-influence-unknown/src/quote-match.ts:229). The existing [verifyQuote helper](/home/greg/code/spideryarn2/.claude/worktrees/citations-influence-unknown/src/citation-lookup.ts:394) also bounds the stored slice and rejects very short quotations.  
  **Fix:** specify the strict pass, non-empty and bounded evidence, finite numeric validation within 0–1, and a database range CHECK alongside the presence CHECK. Specify `withChatJsonSchema`, with every output field required and nullable where appropriate. A schema alone does not establish that a quotation supports the number.

- **F3 — P2, reasoned: starting immediately after search can assess an old row under a fresh fingerprint.**  
  `digFirst()` uses the row loaded when the button was pressed. `prepare()` later reloads the list, resolves the work again, and computes the fingerprint from fresh metadata. See [citation-investigate.ts:943](/home/greg/code/spideryarn2/.claude/worktrees/citations-influence-unknown/src/citation-investigate.ts:943) and [citation-investigate.ts:1018](/home/greg/code/spideryarn2/.claude/worktrees/citations-influence-unknown/src/citation-investigate.ts:1018). A concurrent list regeneration can preserve the id while changing the title or authors.  
  **Fix:** start the influence call only after the final `prepare()`—including its possible second lookup—and give it `prepared.context`. Check the original search extracts against that fresh identity. Save using that same prepared fingerprint.

- **F4 — P2, reasoned: increasing the lease does not protect a parallel call after explicit release.**  
  `reading()` releases the allowance in its inner `finally` as soon as streaming ends, before validation and saving. See [citation-investigate.ts:1136](/home/greg/code/spideryarn2/.claude/worktrees/citations-influence-unknown/src/citation-investigate.ts:1136). An influence promise still running then would outlive admission and could overlap another press. Stream failure also needs to settle or cancel that promise.  
  **Fix:** specify the promise’s full lifetime. The simplest design is a bounded, best-effort influence call after preparation and before streaming, followed by the existing single save. Parallel execution requires cancellation and settlement before releasing admission. Keep one allowance for the whole press; recompute the global fill limit if the revised per-press budget requires it.

- **F8 — P2, reasoned: relevance-only fallback silently imputes influence equal to relevance.**  
  Algebraically, returning `r` is equivalent to using `(2r + i)/3` with `i = r`. For relevance `0.30`, unknown passes the default `0.25` bar, while known influence `0.10` produces approximately `0.233` and disappears. Thus unknown can protect a row relative to a known minor work; the plan’s neutrality claim is too strong. The current formula is at [CitationsPanel.tsx:305](/home/greg/code/spideryarn2/.claude/worktrees/citations-influence-unknown/src/web/BibliographyPanel.tsx:305).  
  **Fix:** explicitly accept and explain this imputation, or use relevance for every row’s threshold and keep influence as its separate ordering option. The latter is the simpler consistent scale.
