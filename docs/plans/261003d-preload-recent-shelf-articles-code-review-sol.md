FIXED.** The effect dependency contained only slugs, so a live shelf reporting a newer revision, rename, visibility, or archive state for the same top five did not rerun. Slots now carry a fingerprint of payload-bearing shelf fields and are replaced when it changes ([usePreloadRecent.ts](/home/greg/code/spideryarn2/.claude/worktrees/fbj78fff-snappier-article-loads/src/web/usePreloadRecent.ts:20), [prefetch-article.ts](/home/greg/code/spideryarn2/.claude/worktrees/fbj78fff-snappier-article-loads/src/web/lib/prefetch-article.ts:83)). - **P2 — Cross-tab or pipeline changes remain stale for at most 60 seconds. NOT FIXED.** Freshness still uses the local write counter plus `LIFE_MS`; another tab or background pipeline publication cannot move that counter ([prefetch-article.ts](/home/greg/code/spideryarn2/.claude/worktrees/fbj78fff-snappier-article-loads/src/web/lib/prefetch-article.ts:47), [prefetch-article.ts](/home/greg/code/spideryarn2/.claude/worktrees/fbj78fff-snappier-article-loads/src/web/lib/prefetch-article.ts:178)). This is an explicit documented trade-off. If stronger freshness is required, reduce the TTL or add cross-tab/server invalidation.
