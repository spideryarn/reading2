1. **High — deleting controls is not scoring-neutral and can change a page’s verdict.** [src/pdf.ts:1056](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/pdf.ts:1056) and [src/pdf-read.ts:1444](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/pdf-read.ts:1444) delete controls. Today the scorer treats them as separators: `alpha\u0002beta` tokenises as `alpha beta`; after deletion it becomes `alphabeta` ([src/pdf-score.ts:257](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/pdf-score.ts:257)). That can cross recall/precision thresholds and can also alter the three-word structural presence gate ([src/pdf-integrity.ts:163](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/pdf-integrity.ts:163)). Replace these controls with a space, then remove the existing default-ignorable noise separately. This matches the repository’s established rule that controls become spaces because deletion joins words ([src/html.ts:116](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/html.ts:116)). Add an end-to-end scoring regression, not just an `itemText` unit test.

2. **Medium — the PDF `metadata` step still accepts NUL from its model output.** Cleaning `firstPagesText` cleans the prompt, not the answer. `paper-metadata` parses model title, authors and abstract with whitespace-only normalization ([src/paper-metadata.ts:207](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/paper-metadata.ts:207)); authors/byline and abstract then reach `Meta` unchanged ([src/paper-metadata.ts:383](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/paper-metadata.ts:383)) and are written directly to JSONB/text ([src/store/artifacts-pg.ts:919](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/store/artifacts-pg.ts:919)). A model-emitted NUL can therefore produce the same 22P05/22021 failure for a minimal PDF import. This is not part of `STEPS.extract`, but it disproves the plan’s broader “exactly two places in the PDF path” claim. Normalize `paper-metadata` answers at `parseAnswer`.

3. **Low — the cached-chunk reasoning is correct for NUL, but not for the widened all-C0 invariant.** Production JSONB cannot contain NUL, so a valid production checkpoint cannot replay this incident. 4. **Low — Crossref/DataCite remains another foreign-text-to-Postgres path, although it does not fail the import.** `plainRegistryText` collapses whitespace but does not remove NUL ([src/bibliographic.ts:293](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/bibliographic.ts:293)); those fields are written to `bibliographic_records` text/text[] columns ([src/store/pg-bibliographic.ts:206](/var/tmp/spideryarn-worktrees/fbu5azdm-pdf-import-22021/src/store/pg-bibliographic.ts:206)).
