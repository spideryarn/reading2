### Findings

- **F1 — P1 — Count is a real sixth role, not metadata.** The plan folds “count” into `--type-meta` ([plan:40](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/docs/plans/261008k-text-styles-for-the-recurring-lines-in-a-mode-band.md:40)), but counts recur independently at materially different sizes: `.cnd-count` is 0.81rem ([referee.css:853](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/referee.css:853)), `.srch-count` 0.83rem ([search.css:592](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/search.css:592)), `.diag-card-count` 0.83rem ([diagram.css:391](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/diagram.css:391)), and `.gloss-count` 0.85rem ([glossary.css:29](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/glossary.css:29)). The original question also named count separately ([q-dhnbhw.md:13](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/docs/user-feedback/questions/q-dhnbhw.md:13)). Add `--type-count`, probably 0.83rem, or explicitly defer counts and remove them from the meta definition. Do not apply it globally to `.gloss-count`, which Quiz also reuses for status sentences ([QuizPanel.tsx:1611](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/QuizPanel.tsx:1611)); use narrower selectors or a semantic role class.

- **F2 — P1 — The quote inventory is semantically wrong and incomplete.** “Words quoted from the article” does not describe `.dbt-quote`, which is copied from a stranger’s page ([DebatePanel.tsx:2439](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/ReceptionAndClaimsPanel.tsx:2439)), or Citations’ extract. Rename the role to “verbatim source words.” More importantly, the plan omits Quotes’ actual quotation, `.quotes-text` at 0.93rem ([quotes.css:90](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/quotes.css:90)). FAQ’s article quotation carries both `.faq-quote` and `.gloss-part-text` ([FaqPanel.tsx:430](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/FaqPanel.tsx:430)), so moving `.gloss-part-text` to `--type-body` would silently classify that quote as explanatory body text. Split or override that case with `--type-quote`.

- **F3 — P1 — Quiz’s question is not a row item, while Citations’ real row title is missing.** Quiz presents one prominent prompt followed by the reader’s answer box ([QuizPanel.tsx:1273](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/QuizPanel.tsx:1273)); its 1.03rem size establishes hierarchy over the 0.94rem premise and input ([quiz.css:70](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/quiz.css:70), [quiz.css:107](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/quiz.css:107)). Make it a named exception now rather than first shrinking it by 11%. Conversely, `.cite-title` is genuinely the title of every citation row, but has no size and inherits the band’s 0.96rem ([citations.css:14](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/bibliography.css:14), [mode-band.css:102](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/mode-band.css:102)); it belongs in the item/title role. `.skim-place` is a reasonable row-context/title member, but it is not necessarily model text—the component voices each path segment separately ([SkimPanel.tsx:760](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/SkimPanel.tsx:760)).

- **F4 — P1 — Several shared or compound selectors will make the proposed test pass without proving the intended result.** `.dbt-group-head` also appears on `.dbt-group-claim`, whose later rule replaces its size with 0.85rem and sentence case ([debate.css:93](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/reception.css:93), [debate.css:112](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/reception.css:112)); test only the uppercase-heading cases or record the claim heading as an exception. `.mir-quote` shares its declaration with `.mir-criterion` ([referee.css:768](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/referee.css:768)), but the latter is the reader’s criterion, not a quotation ([MirrorPanel.tsx:420](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/MirrorPanel.tsx:420)); split that rule. The `.gloss-part-text`/FAQ collision is the same class of problem. Tests should model the full selector and competing declarations, not merely find a token somewhere in a rule naming the class.

- **F5 — P1 — The claimed band scope omits obvious band modes.** The ratchet covers only eleven files ([plan:100](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/docs/plans/261008k-text-styles-for-the-recurring-lines-in-a-mode-band.md:100)), but Search has precisely these recurring jobs: an article quotation and a model explanation ([search.css:800](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/search.css:800)). Illustrated likewise has a model description and author quotation ([diagram-illustrated.css:178](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/diagram-illustrated.css:178)), while Sketch has title/body/meta card lines ([diagram-sketch.css:369](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/diagram-sketch.css:369)). Include Search. Diagram/Sketch/Illustrated may reasonably be excluded because their type is tied to fixed visual compositions, but say so explicitly. The stated exclusions for Marginalia, Structure, outline, chat, and non-band pages are otherwise right.

- **F6 — P1 — A count-only ratchet does not enforce the promised invariant.** One literal can be removed while an unrelated new literal is added, leaving the count unchanged; changing an existing literal’s value is invisible; and a new stylesheet is unguarded by design ([plan:100](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/docs/plans/261008k-text-styles-for-the-recurring-lines-in-a-mode-band.md:100)). A raw-regex implementation would also count comments incorrectly, mishandle nested `@media` rules, and miss `font:` shorthands; the audited sheets already contain many `font: inherit` declarations, such as [quiz.css:123](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/quiz.css:123). If a ratchet is retained, parse CSS with PostCSS and snapshot the exact remaining exceptions as `file + at-rule context + selector + property + value`, including size-bearing `font:` shorthands and `em`/`px`/`calc()` values. That is stronger than a total count. A simpler option is to centralise role membership in a late-loaded `type-roles.css` or explicit `.type-*` classes and test that registry, without pretending a global count can infer semantics.

- **F7 — P2 — `--type-label: 0.72rem` is the least convincing value.** The evidence is evenly split between 0.72 and 0.77, so “two of four already” does not select the smaller value ([plan:56](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/docs/plans/261008k-text-styles-for-the-recurring-lines-in-a-mode-band.md:56)). The 0.77rem headings are sticky navigational headings in Timeline and Ideas ([timeline.css:59](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/timeline.css:59), [ideas.css:60](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/ideas.css:60)); shrinking them to 11.5px partially reverses the earlier readability lift. Prefer 0.77rem, or split persistent group headings from small headings inside cards. Also inspect their `.gloss-count` children, whose own 0.85rem declaration will remain larger than the heading.

- **F8 — P2 — `.tl-blurb` is not metadata, and the visual proof does not test the actual face combinations.** Timeline’s blurb explains its group, analogous to `.ideas-blurb` at the same 0.79rem ([timeline.css:80](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/timeline.css:80), [ideas.css:85](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles/ideas.css:85)); either leave both as intentional small explanatory copy or classify both consistently, rather than moving only Timeline to meta. The `/design` proposal shows each role in one “usual” face ([plan:82](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/docs/plans/261008k-text-styles-for-the-recurring-lines-in-a-mode-band.md:82)), although the item role spans IBM Plex Mono, Geist, and reader Arial, while the quote role spans Source Serif and UI-faced third-party text. The preceding investigation explicitly says those faces still need side-by-side comparison ([261006k:137](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/docs/plans/261006k-text-size-adjust-for-a-landscape-phone-and-a-quick-review-of-fonts-and-sizes.md:137)). Make the design sample a compact role-by-voice matrix, and add an 844×390 landscape-phone screenshot; 390px alone exercises the portrait layout.

The proposed token location is sound: `src/web/styles/tokens.css` is imported before all band sheets ([styles.css:27](/var/tmp/spideryarn-worktrees/fbar65p3-type-sizes-across-modes/src/web/styles.css:27)), so every band and `/design` can see the custom properties. `--type-*` does not collide with Tailwind’s `@theme` namespaces. I also found no `narrow-window.css` or media-query override of the named target selectors; the silent cascade risks are the shared and compound selectors above.

The better reduced plan is: six roles including count; preserve Quiz as a prompt exception; audit every row-based band mode and explicitly defer fixed visual compositions; use component-confirmed selector membership or semantic role classes; replace the numeric ceiling with an exact parsed exception inventory; then screenshot only the modes that actually change, including Search and landscape phone.
